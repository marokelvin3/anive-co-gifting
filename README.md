# ANIVE.CO | GIFTING — Curated Luxury & Bespoke Gift Boxes

A luxury gifting e-commerce platform and atelier web application built for **ANIVE.CO | GIFTING**. Designed with a calm, serene aesthetic, cool eucalyptus and slate palette, tactile typography, and rich micro-interactions.

---

## 🌿 The 15 Specialized Gifting Departments

1. **Bridesmaids Gift Boxes & Bags**: Mulberry silk robes, rose quartz gua sha, custom embroidery, and bridesmaid proposal suites.
2. **Personalised Gift Boxes**: Hot-foil debossed monograms (Gold, Silver, Blind-Deboss) and tailored keepsake stationery.
3. **Emergency & Last-Minute Gifting**: Dynamic cutoff countdown timer, same-day dispatch priority handling, and instant digital unboxing reveals.
4. **Corporate Gifting**: Volume discount calculator, blind-debossed client logos, custom brand ribbons, multi-address CSV drop-shipping, and downloadable executive lookbook.
5. **Birthday & Celebration Gifts**: Sparkling effervescence, gold matchboxes, and artisanal treats for memorable milestones.
6. **Proposal & “Will You Be My…” Gifts**: Meaningful proposal unboxings for Maid of Honour, Bridesmaids, Godparents, and partners.
7. **Wedding & Event Gifting**: Welcome hospitality canvas totes, newlywed suites, and wedding weekend itinerary gift sets.
8. **Anniversary & Romantic Gifting**: Fluted ceramic candleholders, French beeswax tapers, and intimate date night connection cards.
9. **Thank You & Appreciation Gifts**: Restorative teas, hand-thrown mugs, and shea butter pampering for mentors, hosts, and medical professionals.
10. **Custom Gifting (Interactive Box Studio)**: 4-Step DIY builder to select keepsake vessels, handpick 1–6 curated luxury goods, choose custom silk ribbons, and write wax-sealed calligraphy notes with real-time live preview.
11. **Gift Sourcing & Curation**: VIP private sourcing concierge questionnaire for rare vintages, bespoke international items, and gala favours.
12. **Event Favours & Guest Gifts**: Bulk mini soy votives, seed paper tags, and custom wax seals for dinners and showers.
13. **Baby & New Mum Gifts**: Organic GOTS-certified swaddles, natural beechwood rattles, and postpartum botanical care.
14. **Luxury & Premium Gifting**: Scottish cashmere throws, hand-cut crystal coupes, and hand-carved heirloom chests.
15. **Holiday & Seasonal Gifting**: Winter solstice spiced pomander, mulling spices, and limited-edition festive holiday boxes.

## 🎨 Color System & Aesthetics

- **Eucalyptus & Sage**: `#6D9087`, `#53726A`, `#405852` — grounded, restorative botanical luxury.
- **Cool Slate & Sea Salt**: `#586F7C`, `#6485A5`, `#2F4550` — crisp, calming, contemporary refinement.
- **Oyster Pearl & Soft Alabaster**: `#FAF9F6`, `#F4F7F6`, `#F8FAF9` — gentle, tactile paper and linen backgrounds.
- **Accents**: Muted Champagne `#D4AF37`, Brushed Platinum Silver `#C5CAD1`, Pale Rosewater `#DFC3C3`.
- **Typography**: Editorial Serif (`Cormorant Garamond`) paired with modern Sans (`Plus Jakarta Sans`).

---

## ⚡ Tech Stack & Architecture

- **React 18**: Component architecture and state management.
- **Tailwind CSS**: Custom utility design system with calm & cool luxury tokens.
- **Lucide React**: Clean, lightweight iconography.
- **Canvas Confetti**: Celebratory animation upon completing the white-glove checkout.
- **Cart & Customization Context**: Persistent local storage, real-time currency conversion (USD, GBP, EUR, AUD, NGN), promo codes (`WELCOME10`, `VIP15`), and modal management.
- **Vite 6**: Ultra-fast build and hot module replacement.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
